# 看板逐页验收

使用独立数据目录，分别检查空库和带合成行车、充电、定位与 SOC 记录的库。桌面和手机均需通过看板密码登录。本轮使用本机 Chrome，在 1440 × 900 和 390 × 844 两种视口逐页检查，另以 320 像素宽度检查窄屏布局。

| 页面 | 检查操作与预期结果 |
| --- | --- |
| 看板登录 `/login` | 从行程页进入登录，输入错误密码可见错误提示。更正后按回车，返回原行程页，导航标记当前位置。 |
| 概览 `/` | 在空库检查门锁、联网和胎压的未知值。在模拟快照中把续航和速度设为零，应显示零。进入下一轮刷新后，充电剩余时间、胎压、坐标和门锁同时更新。检查普通车模、侧视模式和 WebGL 不可用时的线稿。 |
| 行程 `/drives` | 连续选取有轨迹和无定位点的行程，后者应显示空状态并隐藏旧地图。断开瓦片请求时，仍能查看本地轨迹。常去地点中带引号或空格的名称能完整带入设置表单。 |
| 充电 `/charging` | 对照起始电量 0%、缺失的结束电量及峰值功率 0 kW。依次打开有采样和无采样的会话，曲线与所选会话一致。缩放窗口后检查两条纵轴和月度统计。 |
| 趋势 `/trends` | 空库给出采集提示。有数据时打开即可看到首个信号，切换信号与时间范围后核对标题与曲线。零速度要能绘制，文本值及没有变化记录的时段各有提示。 |
| 电池 `/battery` | 月度里程、近 90 天电量分布、近 7 天电量变化和静置电耗各自处理空数据。电量分布统计有效 SOC 样本。单个接口读取失败时，其余图表仍可加载。 |
| 设置 `/settings` | 从空库绑定合成 VIN，核对尾号。重复提交同一 VIN 应成功，提交另一辆车的 VIN 应提示已绑定。检查地点预填、坐标范围、半径及增删。写入地点后立即下载整库并核对记录，检查 CSV 与空表提示。 |
| 理想账号登录 `/liam-login` | 用模拟流程检查手机号、验证码和错误反馈。手机号应可修改，开始后自动完成滑块；滑块失败时提示“未发送短信”且可立即重试，短信发出后才显示冷却时间。先登录时完成后进入车辆绑定，已有 VIN 时返回概览。模拟凭据保存后关闭面板，后台仍应恢复采集。可用 `LIAM_LOGIN_HEADLESS=0` 在桌面环境观察浏览器实际拖拽。 |

长期回归覆盖看板鉴权、首次绑定、趋势零值与排序、SOC 分桶、地点校验和 SQLite 在线导出。任务生命周期用例检查登录后离开面板、会话失效和自动恢复；MCP 用例在同一次连接中核对绑定前后的数据。[Web 回归用例](../tests/test_web_ui.py) · [任务生命周期用例](../tests/test_service.py) · [本地开发与验证](../CONTRIBUTING.md)

## 2026-11-21 复验记录

- 使用临时数据卷从 Compose 启动服务，打开全部 8 个页面及其本地资源。在设置页绑定合成 VIN 后，概览和已经连接的 MCP 客户端都读到了该车辆的 0% 电量。服务重启后，VIN 尾号和同一条快照仍可读取。
- 模拟账号过期时，实时与历史任务都停止。模拟重登保存凭据后，两项任务各恢复一次。只让实时票据过期时，历史任务持续运行。登录验证使用本地替身，真实短信链路和车端枚举仍待实车确认。
- 云端充电记录先返回 0 kWh，再补齐实际电量时，月度图保留同一次充电并更新用电量。全量 41 项测试通过。另用含行车、充电和电量记录的 SQLite v5 库升级至 v6，核对原有记录并通过完整性检查。
- 通过 Streamable HTTP 调用了全部 15 个只读工具。使用 MCP SDK 1.30.0 的客户端主动断开时，服务端可能记录一次 SSE 写入通道的 `ClosedResourceError`。关闭请求返回 HTTP 200，重新连接后仍可查询服务状态。
